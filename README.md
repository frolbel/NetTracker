# NetTracker

**NetTracker** — это компактная консольная утилита на C#, предназначенная для мониторинга сетевой активности конкретного приложения в Windows в режиме реального времени.

Программа использует механизм **Event Tracing for Windows (ETW)**, что позволяет перехватывать события на уровне ядра ОС. Это гарантирует, что ни одно кратковременное сетевое соединение не будет пропущено.

## Особенности
- **Точность:** Захват TCP-соединений через Kernel-провайдер Windows.
- **DNS Resolution:** Автоматическое сопоставление IP-адресов с реальными именами доменов путем перехвата системных DNS-ответов.
- **Стабильность:** Уникальная идентификация сессии (`Frolbel.NetTracker.Session`) и механизм автоматической очистки ресурсов при запуске и выходе.
- **Фильтрация:** Отслеживание трафика только для указанного пользователем процесса.

## Как это работает
В отличие от обычных утилит, использующих опрос таблицы соединений (как `netstat`), NetTracker подписывается на системные события. Когда целевое приложение выполняет DNS-запрос, утилита запоминает связку "IP-Домен". При последующем TCP-подключении программа мгновенно выводит понятное имя хоста.

## Требования
- Операционная система: Windows 10/11 x64.
- **Права Администратора:** Необходимы для доступа к трассировке событий ядра (ETW).

## Использование
Вы можете использовать NetTracker двумя способами:

### Способ 1: Готовый файл (Рекомендуется)
1. Перейдите в раздел [Releases](https://github.com/frolbel/NetTracker/releases) и скачайте последнюю версию `NetTracker.exe`.
2. Запустите терминал (PowerShell или CMD) **от имени Администратора**.
3. Запустите файл: `.\NetTracker.exe`

### Способ 2: Сборка из исходников
1. Склонируйте репозиторий.
2. Установите [.NET 9.0 SDK](https://dotnet.microsoft.com/download/dotnet/9.0).
3. Соберите проект: `dotnet publish -c Release -r win-x64 --self-contained`.
4. Запустите полученный файл от имени Администратора.

## Работа с программой
1. Введите имя процесса (например, `telegram`, `discord` или `firefox`).
2. Для завершения сбора статистики и вывода итогового списка уникальных ресурсов нажмите `Ctrl+C`.
3. После завершения программа дождется нажатия любой клавиши перед закрытием окна.
