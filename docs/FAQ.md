# Часто задаваемые вопросы (FAQ)

### Почему для браузеров (Chrome, Edge, Яндекс, Firefox) все DNS определяются как «Неизвестный домен»?
Современные браузеры по умолчанию используют технологию **DNS over HTTPS (DoH)**, отправляя запросы в зашифрованном виде. Служба DNS-клиента Windows не видит эти запросы.
**Решение:** Отключите «Безопасный DNS» в настройках браузера на время анализа. Также перед мониторингом рекомендуется очистить внутренний кеш браузера (в Chrome это `chrome://net-internals/#dns`), иначе браузер будет использовать уже известные ему IP-адреса без отправки новых DNS-запросов.

Подробный разбор проблемы и пошаговые инструкции см. в [«Почему я вижу много строк "Неизвестный домен (прямой IP)"?»](TROUBLESHOOTING_UNKNOWN_DOMAIN.md).

### Почему я не вижу запросов при использовании прокси?
Если анализируемое приложение работает через прокси (например, SOCKS5), весь трафик туннелируется на один локальный или удаленный IP-адрес. DNS-резолвинг в таком случае происходит на стороне прокси-сервера или удаленного узла (Remote DNS). В логах вы увидите только подключение к IP-адресу самого прокси (например, `127.0.0.1:10808`).

### Что значит «Прямой IP» в логе?
Это означает, что программа обратилась к серверу напрямую по IP-адресу, без предварительного запроса к DNS (или IP-адрес был закеширован до запуска NetTracker).
